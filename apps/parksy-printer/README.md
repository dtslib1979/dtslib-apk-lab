## 왜 필요한가 — 출판사 실물 하드카피

dtslib-papyrus는 콘텐츠를 전자 형태(웹진, MCP, 유튜브)로만 유통하는 게 아니라
**실물 하드카피가 반드시 필요한 지점**이 있다. 디지털로 끝나는 게 아니라 손에 잡히는
종이 출력물로 마무리되어야 "출판"이 완성되는 워크플로우다.

이걸 매번 사람이 프린터 앞에서 뽑는 대신, 음성 명령 하나로 자동 출력되는
파이프라인을 만드는 게 이 프로젝트의 목적이다.

## 개념

**ESP32 + 열지(감열지) 전표 프린터** — 영수증 프린터 하드웨어를 이용한 저가 출력 라인.

```
음성 STT → Claude Code → ESC/POS bytes → WiFi → ESP32 UART → 열지 출력
```

- 캔버스: 576px 폭 × 무제한 길이, 흑백 1bit
- 프로토콜: ESC/POS (열지 프린터 표준 커맨드셋)
- 타깃 하드웨어: ESP32 (저가 중국 IoT 보드)
- 컨셉명: **Reverse Orality** — 말(음성)이 다시 활자(종이)로 돌아가는 역방향 구술 파이프라인

## 왜 ESP32 + 저가 중국 보드인가

`docs/PARKSY_APK_PHILOSOPHY.md` "Phase: 하드웨어" 로드맵의 첫 번째 구현체.
저가 중국 IoT 제품에 커스텀 펌웨어를 얹어 필요한 만큼만 패치하는 방식 —
완제품을 그대로 쓰는 게 아니라 부품으로 뜯어서 재조립하는 이 레포 전체의 철학과 동일하다
(스마트 글래스 백서 `apps/smart-glass/README.md`와 같은 패턴).

## 아날로그 태블릿 서플라이 체인

이 프로젝트는 "아날로그 태블릿 서플라이 체인"의 첫 번째 레이어로 구상됨 —
디지털 입력(음성)이 물리적 출력(종이)으로 나오는 체인의 시작점.
후속 레이어는 미정.
