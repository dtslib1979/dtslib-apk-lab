# Wearable Audio (이어폰) — 확장 슬롯 (planned)

> **상태: planned — 아직 구체적 용도/앱 미정, 슬롯만 선점**
> [`devices/phone`](../phone)의 확장. 핸즈프리 오디오 입출력 전용.

## 왜 필요한가

폰이 중심이지만, 손이 자유로운 상태에서 오디오 입출력만 필요한 상황이 있다 —
이동 중 음성 명령, 핸즈프리 녹음, 실시간 통역 청취 등. `chrono-call`(통화 녹음 STT)이나
`parksy-glot`(실시간 자막)과 결합될 여지가 있음.
