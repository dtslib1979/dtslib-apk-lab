# Phone — 이 레포의 물리적 중심

> **이 레포(dtslib-apk-lab)는 Android 패키지 기반이다. 그래서 폰이 중심이다.**
> 태블릿·이어폰·글라스는 전부 이 슬롯의 확장이지, 대등한 별도 축이 아니다.

## 위계

```
PC (WSL2)           ← 연산 두뇌. 무거운 작업(빌드, AI 추론, 파이프라인)은 전부 여기서.
  │
  │  ADB             ← APK와 동급으로 중요한 브릿지 프로토콜.
  │                     Good Lock/ADB로 안 되는 것만 APK로 만든다 (ADB 설계 철학).
  ▼
Phone (S25 Ultra)    ← 이 폴더. 온디바이스 계층의 중심.
  │
  │  확장
  ▼
┌───────────┬──────────────┬─────────────┐
│  Tablet   │ Wearable-    │ Smart Glass │
│  (Tab S9) │ Audio (이어폰) │             │
└───────────┴──────────────┴─────────────┘
```

## 구현체

폰 슬롯의 소프트웨어 구현은 [`apps/blackhole`](../../apps/blackhole) — "모든 디바이스를 PC로 연결한다."
CI가 살아있는 실제 빌드 대상이라 여기(devices/)로 옮기지 않고 apps/에 그대로 둔다.
이 README는 개념 지도 역할만 한다.

## 왜 폰이 중심인가

- 레포 이름 자체가 "APK Lab" — Android 패키지가 기본 단위
- 폰은 항상 켜져있고 상시 휴대되는 유일한 디바이스 (태블릿/이어폰/글라스는 필요할 때만 꺼냄)
- ADB 원격 조종의 실제 대상이 폰 (`~/.claude/CLAUDE.md` ADB 설계 철학 — 폰=SSH 클라이언트, PC=연산 노드)
- 다른 슬롯들은 전부 "폰이 못 하는 것"을 보완하는 확장 장비:
  - 태블릿: 큰 화면이 필요한 작업
  - 이어폰: 핸즈프리 오디오 입출력
  - 글라스: 1인칭 POV, 손이 자유로운 방송
