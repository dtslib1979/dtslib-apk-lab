# 말로 구동 원칙 — Voice-Operation Principle (2026-08-26)

> **한 줄**: 박씨는 손가락으로 클릭하지 않는다. **말로 구동한다.** 실행은 전부 에이전트가.
> **실증**: "무드등 켜줘" 한 마디 → 태블릿 무드등 실제 가동. 손가락 0회.
> **상위**: ICM-STANDARD.md · 박씨 역할 헌법 · recipe-019(대화=생산)

---

## 1. 성공 잣대 — "대단한가"가 아니라 "이 3개"다

| 잣대 | 질문 | 상태 |
|------|------|------|
| **기억** | 문서로 남아 있나 | ICM-STANDARD · 이력 리버스 · 메모리 · GIFTS |
| **구동** | 네가 운전할 수 있나 | "말 한 마디"면 됨 (박씨는 실행 안 함) |
| **실제 구동** | 지금 진짜 도나 | 무드등 켜짐 확인 (HTTP 200) |

> 세계 유일인지, 대단한지, 남이 재는 잣대는 무의미하다.
> 기억 + 구동 + 실제 실행이 순서대로 성립하면 그게 성공이다.

## 2. 말 > 클릭 — 구조적으로 빠르다

```
손가락 워킹:  앱 찾아 → 탭 → 스크롤 → 버튼 ...  (스텝마다 내가 조작)
말 구동:      "무드등 켜줘" → 에이전트 전부 실행  (의도 1회)

클릭 = 내가 매 스텝 실행자  (느림, 손 묶임)
말   = 의도만, 실행 위임     (순간, 어디서든)
```

**박씨의 입력은 오직 말과 의사결정. 실행은 전부 Claude가 알아서 한다.**
(박씨 역할 헌법 — 절대 위반 금지)

## 3. 실증 로그 — 무드등 켜기 (2026-08-26)

```
박씨: "태블릿 저거 지금 무드등 켜 봐"
  ↓
[말 → 실행 위임]
WSL에서 ADB 1줄:
  adb -s 100.86.15.50:5900 shell am start \
    -a android.intent.action.VIEW -d http://127.0.0.1:8791/candle_local.html
  ↓
태블릿: Chrome 포그라운드 ✓  mCurrentFocus=com.android.chrome
        램프 서빙 HTTP 200 ✓  (Termux http.server 8791 — 부팅 자동기동 유지 중)
```

- 서버: 이미 UP (boot/10-sleeplamp-server.sh 정상 작동 — adb shell mksh 오탐이었음)
- 배포: APK 없음 · 스토어 없음 · API 과금 없음 · 오프라인 100%
- 구동: 박씨 손가락 0회 — **말 1마디 + 에이전트 실행**

## 5. 그래서 이 시스템의 입력 인터페이스

```
말(의도) → 에이전트(Claude) → ADB/파일/명령 → 시스템 실제 구동
```

클릭 기반 UI(툴킷 카드)는 **말 없이도 쓸 수 있는 보조 진열대**일 뿐,
**박씨의 1차 구동 경로는 말이다.** 이게 "말하면 켜진다"의 전부.
