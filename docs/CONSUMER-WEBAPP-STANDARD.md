# 소비재 웹앱 표준 — APK 불필요 원칙 (2026-08-26)

## 1. 핵심 결론

> **온디바이스 소비재는 웹앱 + 로컬 서버가 표준. APK는 필요 없다.**

```
1 앱 = 1 카드 (toolkit_cards.json 한 줄)
런타임 1회 설치: Termux + Shizuku (기기당 1번)
새 앱 = 파일 몇 개 + 카드 1줄 + scp 1방
업데이트 = 파일 교체 (스토어 심사·서명 없음)
```

| 항목 | 웹앱 (표준) | APK (예외) |
|------|------------|-----------|
| 과금 | 0 (로컬 서빙) | 빌드/서명/유지보수 |
| 오프라인 | 100% (127.0.0.1) | 100% |
| 배포 | scp 파일 1방 | 빌드 + 설치 |
| 업데이트 | 파일 교체 | 재빌드 + 재설치 |
| 검토 | 없음 | (스토어) |

## 2. 예외 — APK가 여전히 필요한 3가지

이 README의 기존 원칙("Good Lock으로 안 되고, ADB로도 안 될 때만 APK")과 동일:

| # | 예외 | 사례 |
|---|------|------|
| ① | **백그라운드 상시 실행** | 화면 꺼도 계속 도는 것 |
| ② | **저수준 하드웨어 제어** | 브라우저 Web API 밖 (오버레이, 카메라/마이크 점유, BT 저수준) |
| ③ | **외부 유통/스토어·결제** | Play Store 출시 |

→ 이 3가지만 `apps/` 에 APK로 남는다. 나머지는 전부 웹앱.

## 3. 두 타입 분기 (상위 표준에서 상속)

```
"이건 클릭해서 쓰는 거냐, 연산이 필요한 거냐?"
  ├─ 클릭해서 씀 (뇌 없음) → 소비재 웹앱 + Toolkit 카드
  └─ 연산 필요 (뇌 있음)   → 생산재 파이프라인 (recipe+MCP+Fab)
```

## 4. 저장 위치 — 양쪽

| 위치 | 역할 |
|------|------|
| 기기 로컬 (`~/candle_srv/`, `~/toolkit_srv/`) | 즉시 실행 (Termux http.server) |
| **본 레포 (apk-lab) GitHub Pages** | **웹앱 소스 보관 + 버전 관리 + 공개 배포** |

> 기존 폐기 문서(`FAB_ARCHITECTURE_FINAL.md` §6 "PWA/APK 폐기")는 **생산재 레인** 대상.
> 소비재 레인에서는 웹앱+로컬서버가 오히려 표준. 시스템 정체성 충돌 없음.
